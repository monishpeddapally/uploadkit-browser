# Contributing

Thanks for helping improve UploadKit.

## Development

```bash
npm install
npm test
```

Keep the core browser package dependency-light. Large codecs should be lazy-loaded adapters rather than mandatory dependencies.

## Pull requests

1. Open an issue for substantial behavioral or API changes.
2. Add or update tests for changed behavior.
3. Run `npm test` before submitting.
4. Keep each pull request focused on one change.

By contributing, you agree that your contributions will be licensed under the MIT License.
